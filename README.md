# siftchord

Sift encode/decode helpers for chord payloads in pipelines.

**Site:** https://theworker02.github.io/siftchord/

## Install / run

```bash
git clone https://github.com/theworker02/siftchord.git
cd siftchord
node src/cli.js
node --test
```
